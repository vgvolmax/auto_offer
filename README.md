# auto_offer
## Windows: запуск одним кликом

Для Windows 10/11 x64 основной способ запуска — распаковать ZIP и дважды щёлкнуть [`start.bat`](start.bat). Launcher без прав администратора загрузит закреплённые portable Python и Node.js внутрь `.runtime`, установит npm-зависимости, проверит и соберёт приложение, запустит его только на `http://127.0.0.1:8765/#/` и откроет браузер. Для остановки используйте [`stop.bat`](stop.bat). После успешной подготовки повторный неизменённый запуск работает без сети.

Прямое открытие `app/index.html` через `file://` **не поддерживается**: приложению нужны Vite production build, HTTP-сервер и постоянный origin для IndexedDB. Подробности и восстановление после ошибок: [Windows portable launch](docs/app/WINDOWS_PORTABLE_LAUNCH.md).
