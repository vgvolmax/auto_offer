# Auto Offer

## Windows portable release

Пользователь скачивает готовый `Auto-Offer-*-windows-x64.zip` из artifacts/release,
полностью распаковывает его и запускает `start.bat`. GitHub **Source code (zip)** не
является пользовательским дистрибутивом. Открытие `dist/app/index.html` напрямую
через `file://` не поддерживается: постоянный origin приложения —
`http://127.0.0.1:8765/#/`.

Node.js, npm и Python устанавливать вручную не требуется, терминал и права
администратора также не нужны. React/Vite уже собран в CI. При первом запуске
интернет нужен только для загрузки официального portable Python 3.13.7. Launcher
проверяет точный состав, размеры и SHA-256 всех файлов runtime перед повторным
использованием; повреждённая установка переустанавливается, а прерванная публикация
восстанавливается из проверенного `.runtime/python.previous` до обращения к сети.
Повторный запуск неизменённого release работает offline. Для штатной остановки
используйте `stop.bat`.

Данные приложения находятся в IndexedDB выбранного браузера и профиля. Они
привязаны к origin; обновление release с тем же origin и удаление `.runtime` их не
удаляют. Другой браузер/профиль имеет другое хранилище. Очистка данных сайта в
браузере может удалить каталоги и черновики.

Разработчикам нужны Node.js/npm; эти инструменты применяются только в development
и CI, а не launcher-контуре. Подробности: [Windows portable launch](docs/app/WINDOWS_PORTABLE_LAUNCH.md).
