# B5a: line decisions, feedback and AI export

## Реализованный план

1. SelectionState нормализуется с legacy 1.0.0 до 1.1.0 и отдельно хранит решения и feedback в существующем IndexedDB store.
2. Сервисы поддерживают выбор товара, `no_offer`, очистку решения и сохранение необязательной обратной связи с optimistic concurrency.
3. Review model считает решение по каждой строке, сохраняет позиции кандидатов и предоставляет фильтры/сводку.
4. UI представляет кандидатов и «Без предложения» как взаимоисключающие решения; feedback редактируется локальным draft, а связанный товар выбирается inline.
5. Чистый builder создаёт детерминированный самодостаточный AI JSON, после чего browser helper скачивает один файл и освобождает object URL.
6. B5a не подтверждает сессию и не создаёт human-oriented export; эти возможности остаются запланированными для B5b.
